# Weights

The `.pt` files are not generated by this project. Place them in this folder
(or pass another path with `--model` / `--face-model`).

| File | Used for | Source | License | Size |
|---|---|---|---|---|
| `yolov8m.pt` | Person and vehicle detection (COCO) | [Ultralytics YOLOv8](https://github.com/ultralytics/ultralytics) | AGPL-3.0 | ~50 MB |
| `face_yolov8m.pt` | Face detection for optional `--blur-faces` | Third-party YOLOv8 face detector | TODO: to be confirmed | ~50 MB |

## yolov8m.pt

Official Ultralytics COCO-pretrained YOLOv8 medium model. If the file is
missing, Ultralytics normally downloads official model names automatically on
first use (for example `--model yolov8m.pt`). Other official models such as
`yolov8n.pt` or `yolov8x.pt` can be used the same way.
